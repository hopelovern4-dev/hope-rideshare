## 📱 What Is HOPE?

HOPE is a lightweight, single-file rideshare web app built for women in Chattanooga, TN. It includes three panels in one app:

- **👩 Rider App** — Book a ride, see fare estimate, pay via CashApp/PayPal
- **🚗 Driver Console** — Accept/decline rides, manage active trips, handle cancellations
- **⚙️ Admin Dashboard** — Track revenue, trip count, cancellations, and system logs

## 📲 Features

- **Real fare estimates** based on actual Chattanooga distances
- **Interactive maps** (OpenStreetMap via Leaflet) with pickup/dropoff markers
- **SMS driver alerts** — driver gets a text the moment a rider books
- **CashApp deep link** pre-filled with fare amount (`$HopeCasey75`)
- **PayPal payment** option
- **Ride log export** as a `.txt` file
- **Lost & Found fee** button for driver toolkit
- **No-car-seat cancellation** safety enforcement

---

## 🛠 Tech Stack

- Pure HTML + CSS + JavaScript (zero frameworks, zero build steps)
- [Leaflet.js](https://leafletjs.com/) for maps
- [Twilio](https://twilio.com) for SMS alerts (via Base44 backend function)
- Hosted free on [Netlify](https://netlify.com)

## 🚀 Deploying

### Netlify (recommended)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag `index.html` onto the page
3. Rename your site to `hoperideshare`

### Glitch
1. New Project → glitch-hello-webpage
2. Replace `index.html` content with this file

### Replit
1. New Repl → HTML/CSS/JS
2. Paste `index.html` content → Run
